# Portfólio de Ivan Costa

Site pessoal com meus projetos, feito com HTML, CSS e JavaScript, sem frameworks.

## O que tem no site

- **Vitrine do Futebol:** meu TCC, um aplicativo que reúne peneiras de futebol (React Native, Node.js e MySQL). A abertura do site tem uma amostra interativa dos filtros do app.
- **Ferramentas de RH na SKA:** assistente de IA, automações de formulários e o site interno de Pessoas & Cultura.
- **Dilton's 7ech:** meu primeiro projeto, de 2024, feito com HTML e CSS.

## Arquivos

| Arquivo | Para que serve |
| --- | --- |
| `index.html` | Leva o visitante para a pasta `portifolio/` |
| `portifolio/index.html` | A página do portfólio |
| `portifolio/style.css` | O visual (cores, fontes e layout, com tema claro e escuro) |
| `portifolio/script.js` | A amostra interativa do Vitrine do Futebol |
| `portifolio/projeto1.html` | Endereço antigo do projeto da loja, redireciona para o portfólio |
